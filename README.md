# 外部调研 · WorkBuddy 技能

> 先找轮子，再找参照系。任何「从零做」的决定，必须先证明外部确实没有现成的。

一个给 WorkBuddy 用的「调研破局」技能。两个入口、同一内核：

- **A · 动手前先找轮子**：准备写代码/搭工具前，把包仓库、代码托管、产品市场、教程、社区、技能市场六个源翻一遍，输出方案对比表 + 明确结论（复用/二开/借鉴/自研）。
- **B · 卡住时破局调研**：持续微调却不见突破、路线存疑时，用「全链路拆解 → 逐环节外部调研 → 不合理点分级 → 破局对策」换姿势，而不是在错误方向上磨到死。

## 触发词（自然语言即可，WorkBuddy 会自动匹配）

- 我想做一个 X／有没有现成的／有没有开源的／别重复造轮子
- 有没有人做过／陷入死胡同／穷尽所有方法／找开源案例
- 对标行业做法／发现不合理的地方

## 安装方式

**方式一：从 GitHub 一键导入（推荐）**
在 WorkBuddy 对话框输入：

```
/skillsimport https://github.com/<你的用户名>/<仓库名>
```

WorkBuddy 会自动克隆仓库、识别 `SKILL.md`、安装到全局技能目录。

**方式二：本地文件夹导入**
1. 把本仓库（含 `SKILL.md`）整体克隆/下载到本地；
2. 将文件夹复制进 WorkBuddy 的 `skills` 目录；
3. 重启 WorkBuddy，输入 `/skills` 查看是否加载成功。
